# rfsd_analysis_2023_NabiullinaGN
Промежуточная аттестация №2
Слушатель: Набиуллина Гульназ
Цель: анализ набора данных RFSD — финансовая отчётность российских компаний.

Загрузка и предобработка данных
Источник данных — открытый датасет RFSD на платформе Hugging Face (irlspbru/RFSD). Данные хранятся в формате Apache Parquet с партиционированием по годам. Для анализа выбран срез за 2023 год.
Пайплайн загрузки:
- С помощью класса HfApi из библиотеки huggingface_hub выполнила запрос list_repo_files() к репозиторию irlspbru/RFSD (тип: dataset). 
- Получила полный список путей ко всем файлам репозитория.
- Из списка отобрала файлы, удовлетворяющие двум условиям: путь начинается с RFSD/year=2023 и расширение .parquet. Из отфильтрованного списка выбрала первый файл.
- Скачала файл через hf_hub_download() с автоматическим кешированием в директорию ~/.cache/huggingface/hub. При повторных запусках используется кеш — повторное скачивание не выполняется.
- Год отчётности извлекла из пути к файлу с помощью регулярного выражения year=(\d{4})' . Значение сохранила в переменную reporting_year; при отсутствии совпадения используется значение 2023.
- Чтение Parquet выполнила библиотекой polars (pl.read_parquet) с двумя параметрами-ограничителями: n_rows=1000 — загружаются только первые 1000 записей для быстрого прототипирования; columns=cols_to_load — загружаются только 14 колонок из полного набора, что снижает потребление памяти.
- Коды строк бухгалтерской отчётности (line_1100, line_2110 и т.д.) переименовала в понятные названия полей(fixed_assets, revenue, net_profit, cash_flow_op, money_in, money_out и др.) через df.rename().
- Добавила столбец year с фиксированным значением через pl.lit(reporting_year).alias('year').
- Данные перевела из Polars DataFrame в Pandas DataFrame (df_pl.to_pandas()) для использования библиотек seaborn, matplotlib и встроенных методов статистики Pandas.

- Рассчитала полную описательную статистику методом df.describe(include='all').

- Для визуализации выбрала три колонки: revenue (выручка), net_profit (чистая прибыль), total_assets (всего активов) — как ключевые индикаторы масштаба и эффективности бизнеса.
- Построила гистограммы с наложением двух вертикальных линий: медиана (синий пунктир) — опорное значение «типичной» компании, устойчивое к выбросам; 99-й перцентиль (красный пунктир) — граница, отделяющая 99% данных от верхнего 1% экстремальных значений. Для net_profit добавила линию безубыточности (y = 0) для визуальной оценки доли прибыльных и убыточных компаний.
- Реализовала функцию safe_stats(), которая для каждой колонки вычисляет Q1 (25-й перцентиль), Q3 (75-й перцентиль), межквартильный размах IQR = Q3 − Q1, границы выбросов [Q1 − 1.5·IQR, Q3 + 1.5·IQR], количество значений за пределами границ и их долю от общего объёма, отношения mean / median и max / min.
- Для каждой колонки вывела топ-3 максимальных и топ-3 минимальных ненулевых значений (методы nlargest / nsmallest) с указанием ИНН и года — для идентификации конкретных компаний-аномалий.
- Обнаружены аномалии: фирмы с активами 9–10 руб. и нулевой выручкой; компании с убытком, многократно превышающим выручку; доля убыточных компаний — ~30–37% от выборки с заполненными данными.

- Вывела матрицу корреляции с цветовой шкалой coolwarm. Коэффициент корреляции Пирсона (df.corr()) по всем числовым колонкам. Значения коэффициентов выведены в ячейках.
- Реализовала автоматический поиск сильных связей: перебор всех пар колонок (исключая диагональ) с порогом |r| > 0.7. Найденные пары отсортированы по убыванию модуля коэффициента.
Пары с высокой корреляцией:
total_assets ↔ total_liabilities	≈ 1.0	Бухгалтерское тождество: Активы = Пассивы
revenue ↔ gross_profit	≈ 0.95	Каскадная формула: валовая прибыль = выручка − себестоимость
current_assets ↔ short_debt	≈ 0.90	Финансирование оборотных активов за счёт краткосрочных обязательств
equity ↔ total_assets	≈ 0.85	Рост собственного капитала синхронно с масштабом компании
Вывод: все высокие корреляции объясняются структурой бухгалтерских форм, а не независимыми экономическими закономерностями.

- Для четырёх пар с высокой корреляцией построила диаграммы рассеяния (sns.scatterplot) с наложением линии линейной регрессии (sns.regplot). На каждом графике указан фактический коэффициент корреляции Пирсона.
Результаты: 
- total_assets ↔ total_liabilities (активы & пассивы) — точки лежат на идеальной прямой под 45°, подтверждение балансового тождества; 
- revenue ↔ gross_profit (выручка & валовая прибыль) — восходящий тренд с разбросом, отклонения от линии отражают разную маржинальность бизнеса; 
- current_assets ↔ short_debt (оборотные активы & краткосрочный долг) — линейная зависимость, малый бизнес финансирует оборотный капитал краткосрочными заимствованиями; 
- equity ↔ total_assets (капитал & активы) — положительный тренд с двумя кластерами, компании на собственных средствах и компании с высокой долей заёмного капитала.

- Сформировала текстовый отчёт, обобщающий результаты по всем этапам.
